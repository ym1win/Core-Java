## 🎯 Learning Objective

The primary objective of this repository is to build a strong understanding of Core Java by:

- Understanding concepts instead of memorizing syntax
- Implementing concepts independently in Java
- Experimenting with code to understand how things actually work
- Solving practice problems after learning each concept
- Maintaining concise and useful revision notes
- Building consistency through Git and GitHub
- Creating a long-term reference for Java revision

## 🌱 Git & GitHub Workflow

GitHub is being used to track my learning progress and maintain my codebase.

Typical workflow:

```bash
git status
git add .
git commit -m "Added <concept> examples"
git push
```

### Commit Philosophy

Commits are made around **meaningful learning progress**, rather than every tiny code change.

Examples:

```text
Added variables and data types examples
Added type casting examples
Added conditional statements
Added loop implementations
Added array basics
Added OOP fundamentals
```

This keeps the Git history meaningful and easy to understand.
